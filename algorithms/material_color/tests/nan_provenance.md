# NaN contrast regression provenance

The vectors in `fixtures/nan_contrast_2026.tsv` were generated by executing the
official TypeScript implementation from a clean checkout of the canonical
Material Color Utilities repository at commit `5b3618b16fdc3825e21d5679bafd144662088ea1`.
The calculation source is `typescript/dynamiccolor/dynamic_color.ts` (SHA-256
`418d22e153309a8f3a105606700e5c97f3440e5a597c16e4734bdfa0aab707c8`), matching
the pinned source hash recorded in `provenance.md`.

Run from the Amane repository root:

```sh
set -eu
MCU_REPO="${MCU_REPO:?Set MCU_REPO to a clean checkout at commit 5b3618b16fdc3825e21d5679bafd144662088ea1}"
MCU_REPO="$(cd "$MCU_REPO" && pwd -P)"
MCU_TS_ROOT="$MCU_REPO/typescript"
BUILD_DIR="$(mktemp -d)"
trap 'rm -rf "$BUILD_DIR"' EXIT
mkdir -p "$BUILD_DIR/deno-cache"
DENO_DIR="$BUILD_DIR/deno-cache" \
  deno run --unstable-sloppy-imports \
    --allow-read="$MCU_TS_ROOT,$PWD/algorithms/material_color/tests/reference" \
    --allow-write="$BUILD_DIR" \
    algorithms/material_color/tests/reference/generate_nan_2026.ts \
    "$MCU_TS_ROOT" \
    "$BUILD_DIR/nan_contrast_2026.tsv"
cmp "$BUILD_DIR/nan_contrast_2026.tsv" \
  "$PWD/algorithms/material_color/tests/fixtures/nan_contrast_2026.tsv"
```

The generator imports and calls the pinned TypeScript `DynamicScheme`,
`MaterialDynamicColors`, and `Contrast` implementations; it does not port the
color calculation. It requests spec 2026 so the four listed variants
(Neutral, Tonal Spot, Vibrant, Expressive) use their official effective 2025
fallback. The small sample covers light and dark modes, NaN contrast, and both
contrast-adjustment paths where upstream exposes a qualifying role. The chosen
base tones already satisfy their contrast curve, but canonical 2025 handling
still recalculates because `NaN >= 0` is false. In particular, N001 is the
single-color path regression that fails before the Rust predicate fix and
matches the upstream tone and packed ARGB output after it.

When originally generated, only this new generator and fixture were added; the
existing finite and alpha reference fixtures were not regenerated or modified.
The portable reproduction command writes to a temporary workspace and compares
that output with the checked-in fixture without changing repository files.
