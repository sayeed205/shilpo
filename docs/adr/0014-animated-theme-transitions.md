# ADR-0014: Animated Material 3 Theme Transitions

- **Status**: Accepted
- **Date**: 2026-08-13
- **Author**: Shilpo Core Team
- **Issue**: [#87](https://github.com/shilpo-rs/shilpo/issues/87)

## Context

When system-wide theme changes occur (mode toggle, seed color update, wallpaper extraction), replacing rendered Material 3 color tokens instantaneously in one frame causes visual harshness and flickering across the shell UI. Perceptual color animation requires pure OKLCH color space math without introducing OS or GPUI dependencies into cross-platform crates.

## Decision

1. **Cross-Platform Pure OKLCH Math (`shilpo-theme`)**:
   - `shilpo-theme` owns `interpolate_argb_oklch(from: u32, to: u32, t: f32) -> u32`.
   - Converts ARGB colors through the standard direct linear-sRGB → LMS/Oklab → OKLCH matrices.
   - Interpolates Lightness ($L$), Chroma ($C$), and Alpha ($A$) linearly.
   - Interpolates Hue ($h$) along the shortest circular arc across $0^\circ/360^\circ$.
   - Handles achromatic colors (Chroma $< 1\text{e}-4$) cleanly without arbitrary hue rotation.
   - Clamps non-finite $t$ safely (`t <= 0` returns `from` byte-exact, `t >= 1` returns `to` byte-exact).
   - Zero I/O, zero system or GPUI dependencies.

2. **Rendered Token Interpolation (`shilpo-ui`)**:
   - `shilpo-ui` depends on `shilpo-theme` (consistent with ADR-0002).
   - `ThemeColor::interpolate(&self, target: &ThemeColor, t: f32) -> ThemeColor` enumerates every Material 3 color role generated by the `roles!` macro.
   - At completion ($t \ge 1.0$), installs `target` byte-exact.

3. **Shell Transition Controller (`desktop/shilpo`)**:
   - `ThemeTransition` and `cubic_bezier_emphasized` (M3 Emphasized Easing `cubic_bezier(0.2, 0.0, 0.0, 1.0)`) drive color frames on GPUI's executor.
   - Default duration is $300\text{ ms}$, configurable via `[theme] transition_duration_ms` in `0..=5000\text{ ms}`.
   - `reduced_motion = true` or `transition_duration_ms = 0` applies theme updates immediately without starting an animation task.
   - Initial daemon population on startup applies immediately without animation.
   - Latest-wins / Interruptible: A new theme update increments the atomic generation counter (`ACTIVE_GENERATION`). Stale tasks notice on their next tick, record `outcome = "superseded"` / `interrupted = true` on the `shilpo_profile` span, and exit without writing colors, wallpaper, completion state, or D-Bus signals.
   - The new transition starts from the colors currently displayed on screen (`Theme::global(cx).colors`), ensuring smooth interruptible transitions.

4. **Observability**:
   - One `shilpo_profile` span (`theme_transition`) is emitted per animated transition recording `from_revision`, `to_revision`, `duration_ms`, `outcome` (`"completed"` or `"superseded"`), and `interrupted`. Per-frame events/spans are omitted.

## Consequences

- Smooth, perceptually natural OKLCH color transitions across all Material 3 UI surfaces.
- Zero thread-blocking or GPUI thread stalls; frames are driven asynchronously on GPUI's executor.
- Full compliance with accessibility preferences (`reduced_motion`) and configurable transition timing.
